# Module 1 · Basics

By the end of this module you'll be able to install charts from a public repo, understand what's inside a chart, build your own chart from scratch, override its configuration, and safely upgrade/rollback a release.

Make sure you've completed [Prerequisites](../docs/prerequisites.md) first.

## Lessons

1. [What is Helm?](01-what-is-helm/) — concepts: charts, releases, repos
2. [Install & Setup](02-install-and-setup/) — confirm your environment works end-to-end
3. [Helm Basic Commands](03-helm-basic-commands/) — install a chart from a public repo
4. [Chart Anatomy](04-chart-anatomy/) — what's inside a chart, generated with `helm create`
5. [Your First Chart](05-your-first-chart/) — build a chart from scratch
6. [Values & Templates](06-values-and-templates/) — configure your chart without editing templates
7. [Upgrade, Rollback & Uninstall](07-upgrade-rollback-uninstall/) — the release lifecycle

Work through them in order — each one assumes you completed the last.
